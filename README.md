- **AI 扒谱**：音频 → SheetSage2 / MERT 转 MIDI，自动分离人声旋律、器乐旋律与和弦轨。
- **四角色编配**：单人独奏 / 双人 1P 主音 / 双人 2P 和弦 / 双人 2P 品格。
- **自动演奏**：30 帧反向预调度，把音符编译成键鼠动作，在游戏里按 1ms 级时间轴演奏。
- **钢琴卷帘**：按真实指法显示弦/品/页，可拖动、试听、微调后直接重编。
- **双主题界面**：Studio Dark / Modern Light，统一微软雅黑 UI 字体。

## 快速上手（三步）

1. 双击 **`双击启动-异键演奏.bat`**，UAC 弹窗选“是”。
2. 在「AI 智能扒谱」页选择原始音频（输出目录默认 `out`），点 **「一键全流程智能扒谱」**；
   也可以直接在「吉他自动演奏」页用 **「打开 MIDI 乐谱」** 载入现成 MIDI。
3. 在「吉他自动演奏」页选角色，按界面三步指引进游戏摆好轮盘，
   点 **「指示圈校准轮盘」** 校准，然后按 **F8** 开始演奏。

## 两种使用方式

### A. 完整包（普通用户推荐）

- 把**整个文件夹**复制到任意路径（例如 `D:\异键演奏`、桌面或 `C:\异键演奏 - 副本`），
  **不要只移动里面的单个文件**。文件夹名可以带中文、空格，也可以换盘符。
- 双击 `双击启动-异键演奏.bat` 即可。启动器优先使用包内 `runtime\python311`，
  该运行时通过 `runtime\python311\Lib\sitecustomize.py` 纯相对路径找包，**连 `pyvenv.cfg` 都不用改**，
  复制/改名/带空格/换电脑都能直接启动。
- 到新电脑后，建议先双击 **`双击环境自检.bat`**，确认显卡、模型、音频与界面都正常。
- 系统要求：Windows 10/11 64 位；演奏需要管理员权限（否则键鼠送不进游戏）。

### B. GitHub 源码（开发者）

- 安装 64 位 **Python 3.11**（python.org），安装时勾选 “Add python.exe to PATH”。
- 双击 `setup\一键配置环境与模型.bat`：自动创建 `.venv` / `vendor\sheetsage2\.venv`
  并下载依赖。模型权重约 2.6GB，且是 **gated** 仓库——按脚本提示在 HuggingFace
  模型页接受条款并登录一次即可。
- 双击 `双击环境自检.bat`，再双击启动器。
- 模型权重为 **CC BY-NC 4.0（仅限非商业）**，第三方许可见 `licenses\`。

## 常见排障

- **按键没反应**：确认以管理员启动、游戏窗口在最前面；游戏建议设为“无边框窗口化”。
- **轮盘位置不对**：演奏页点「指示圈校准轮盘」，拖圆心、滚轮缩放，回车确认。
- **扒谱没声音/很慢**：先点顶部「环境与显卡体检」或双击 `双击环境自检.bat`，
  确认推理设备是 XPU / CUDA / CPU 中实际可用的那一个。
  **AMD 显卡使用 CPU 转录**（一首歌约 2~4 分钟，属正常速度）。
- **换电脑后打不开**：先双击 `双击环境自检.bat`；启动器会自动修复虚拟环境路径。
  如果仍然打不开，重新运行 `setup\一键配置环境与模型.bat`。
- **界面字体发虚**：系统需安装「微软雅黑 UI」（Windows 10/11 自带）。

## 目录说明

```text
main.py                 统一入口
gui_main.py             主窗口（两个标签页）
gui_theme.py            双主题与控件样式
transcriber/            AI 扒谱流水线（SheetSage2 / MERT）
player/                 指法编译、预调度、键鼠执行、钢琴卷帘
assets/test_midis/      内置示例曲 sample_demo.mid
vendor/sheetsage2/      推理环境、模型权重、CLI
runtime/python311/      便携 Python 3.11 运行时（完整包自带）
setup/                  环境配置、模型下载、虚拟环境自愈
logs/                   运行与自检报告
out/                    扒谱输出目录（默认）
```
